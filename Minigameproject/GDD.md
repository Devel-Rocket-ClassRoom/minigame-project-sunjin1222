# GDD - 용사의 연대기

## 1. 문서 개요

- 문서 목적: 현재 Unity 프로젝트에 구현된 완성 게임을 기준으로 게임 디자인 문서를 재정리한다.
- 기준 버전: 2026-06-08 현재 프로젝트 구현 상태
- 대상 플랫폼: PC
- 엔진: Unity
- 장르: 싱글 플레이 덱빌딩 로그라이트 / 타일 배치 전투
- 핵심 키워드: 작가, 원고, 에피소드 진행, 카드 덱 성장, 3x4 보드 배치, 순서 발동, 체인, 증거

## 2. 게임 개요

`용사의 연대기`는 작가 캐릭터를 선택해 에피소드 맵을 진행하고, 각 전투에서 카드 모양의 타일을 3x4 보드에 배치해 적을 쓰러뜨리는 덱빌딩 로그라이트 게임이다.

플레이어는 매 턴 손패에서 카드를 보드에 배치한다. 배치된 카드는 보드의 읽기 순서에 따라 발동하며, 카드의 발동 순서, 인접 카드 수, 남은 빈 칸 수, 보유 자원에 따라 효과가 달라진다. 전투 승리 후에는 카드를 획득하고, 엘리트 전투에서는 유물을 얻어 런을 강화한다.

## 3. 디자인 목표

- 덱빌딩의 익숙한 흐름에 퍼즐형 공간 배치를 결합한다.
- 카드를 단순히 사용하는 것이 아니라, 어디에 놓고 어떤 순서로 발동시킬지 고민하게 한다.
- 캐릭터마다 다른 핵심 키워드와 자원 구조를 제공한다.
- 짧은 에피소드 단위로 선택, 전투, 보상, 휴식을 반복하게 한다.
- 전투 중 적 의도, 체력, 방어도, 피해 제한, 카드 미리보기 등을 통해 판단 정보를 명확히 제공한다.

## 4. 플레이어 경험

### 4.1 핵심 감정

- 손패와 보드 공간을 맞춰 넣는 퍼즐감
- 카드 발동 순서를 설계하는 전략감
- 보상으로 덱이 성장하는 누적감
- 에피소드가 열리며 앞으로 나아가는 진행감

### 4.2 플레이 흐름

1. 타이틀 화면에서 게임 모드를 선택한다.
2. 캐릭터를 선택한다.
3. 스토리를 시작하거나 저장된 런을 이어 한다.
4. 큰 지도에서 해금된 에피소드를 선택한다.
5. 에피소드 안의 후보 구역 중 3개를 선택한다.
6. 선택한 구역을 순서대로 실행한다.
7. 전투, 이벤트, 휴식을 처리한다.
8. 에피소드를 완료하면 다음 에피소드가 해금된다.
9. 최종 에피소드의 보스를 처치하면 게임 클리어가 표시된다.
10. 플레이어 체력이 0이 되면 게임 오버가 표시되고 런 데이터가 초기화된다.

| MapScene | 큰 지도, 에피소드 선택, 구역 3개 선택, 이벤트/휴식 처리, 덱 확인, 저장 |

## 6. 핵심 게임 루프

### 6.1 런 루프

1. 캐릭터 선택
2. 시작 덱과 시작 유물 세팅
3. 에피소드 선택
4. 구역 3개 선택
5. 구역 실행
6. 전투 승리 또는 이벤트/휴식 완료
7. 카드/유물/체력/덱 상태 갱신
8. 에피소드 완료 및 다음 에피소드 해금

### 6.2 전투 루프

1. 덱을 섞고 손패 6장을 뽑는다.
2. 플레이어가 카드를 3x4 보드에 배치한다.
3. 필요하면 배치 초기화 또는 다시 뽑기를 사용한다.
4. 턴 종료 버튼을 누른다.
5. 손에 남은 카드를 버린다.
6. 배치된 카드가 보드 순서대로 발동한다.
7. 적이 생존하면 적 행동을 실행한다.
8. 플레이어 방어도를 초기화한다.
9. 보드 카드를 버림 더미로 보내고 보드를 비운다.
10. 손패 6장을 다시 뽑는다.

## 7. 전투 시스템

### 7.1 보드

- 크기: 3열 x 4행, 총 12칸
- 카드는 `tileShape`와 `tileOrigin`을 가진다.
- 카드의 타일 모양이 보드 밖으로 나가거나 이미 배치된 칸과 겹치면 배치할 수 없다.
- 배치된 카드는 원점 칸을 기준으로 하나의 카드로 취급된다.
- 배치 초기화 버튼을 누르면 보드의 모든 카드를 손패로 되돌린다.

### 7.2 카드 발동 순서

- 보드의 0번 칸부터 마지막 칸까지 순회한다.
- 같은 카드가 여러 칸을 차지하더라도 원점 기준으로 한 번만 발동한다.
- 먼저 발견되는 카드부터 1, 2, 3... 순서로 발동한다.
- 발동 중인 카드는 하이라이트로 표시된다.

### 7.3 인접 판정

- 상하좌우로 붙어 있는 다른 카드의 원점 수를 센다.
- 같은 카드가 차지한 칸은 인접 카드로 계산하지 않는다.
- 체인 효과는 인접 카드 수에 따라 피해 또는 방어도를 추가한다.

### 7.4 손패, 덱, 버림 더미

- 전투 시작 손패: 6장
- 매 턴 시작 손패: 6장
- 덱이 비면 버림 더미를 섞어 덱으로 되돌린다.
- 전투 중 전체 덱, 뽑을 더미, 버린 더미를 확인할 수 있다.
- 전투 승리 후 카드 보상으로 획득한 카드는 현재 런 덱에 추가된다.

### 7.5 다시 뽑기

- 전투당 최대 2회 사용 가능
- 현재 손패를 모두 버리고 같은 수만큼 다시 뽑는다.
- 사용할 때마다 플레이어 체력 5를 잃는다.
- 체력이 0이 되면 게임 오버 처리된다.

### 7.6 체력과 방어도

- 플레이어 체력은 런 전체에서 유지된다.
- 방어도는 피해를 먼저 막는다.
- 적 행동 후 플레이어 방어도는 초기화된다.
- 적 방어도는 플레이어 카드 발동 후 적 행동 직전에 초기화된다.
- 휴식으로 체력을 회복할 수 있다.

### 7.7 적 체력, 방어도, 피해 제한

- 적은 체력, 방어도, 가시, 턴당 최대 피해 제한을 가질 수 있다.
- 턴당 최대 피해 제한이 있는 적은 해당 턴에 받을 수 있는 피해가 제한된다.
- 적이 피해를 받으면 피해 제한 UI가 갱신된다.
- 적의 피해 제한 카운트는 다음 플레이어 턴 시작 전에 초기화된다.

### 7.8 가시

- 가시를 가진 적에게 공격 카드로 피해를 주면 플레이어가 반사 피해를 받는다.
- 일부 효과는 반사 피해를 발생시키지 않도록 처리된다.
- 적 행동으로 가시 수치가 증가할 수 있다.

## 8. 카드 효과 키워드

| 키워드 | 설명 |
| --- | --- |
| 피해 | 적에게 피해를 준다. |
| 방어도 | 플레이어에게 방어도를 부여한다. |
| 체인 | 인접한 카드 수에 따라 피해 또는 방어도가 증가한다. |
| 서사 N | 카드가 N번째 이상으로 발동할 때 추가 효과를 얻는다. |
| 증거 | 추리 작가 전용 전투 자원. 획득 후 일부 효과의 조건 또는 비용으로 사용된다. |
| 의심 N | 증거가 N 이상이면 추가 피해 또는 방어도를 얻는다. 증거를 소비하지 않는다. |
| 추리 N | 증거 N개를 소비해 추가 효과를 얻는다. |
| 추리 ALL | 보유 증거를 모두 소비하고 소비량에 비례한 효과를 얻는다. |

### 10.2 적 행동 타입

| 행동 | 설명 |
| --- | --- |
| Attack | 플레이어에게 피해를 준다. |
| Defense | 적에게 방어도를 부여한다. |
| Buff | 적의 공격 보너스를 증가시킨다. |
| ThornsBuff | 적의 가시 수치를 증가시킨다. |
| Charge | 힘을 모으는 행동. 직접 수치 변화는 없다. |

### 10.3 적 패턴 모드

- `Sequential`: 등록된 패턴을 순서대로 반복한다.
- `PeriodicBuffRandom`: 같은 행동이 바로 반복되지 않도록 무작위 행동을 고르고, 지정 턴마다 버프 행동을 넣을 수 있다.
- 패턴 루프가 돌 때 `attackIncreasePerPatternLoop`에 따라 공격 피해가 증가할 수 있다.

## 11. 보상 시스템

### 11.1 카드 보상

- 전투 승리 후 카드 보상 버튼이 표시된다.
- 캐릭터별 보상 카드풀이 있으면 해당 풀을 우선 사용한다.
- 카드 3장이 무작위로 제시된다.
- 플레이어가 선택한 카드 1장이 현재 런 덱에 추가된다.

### 11.2 엘리트 유물 보상

- 엘리트 전투 승리 시 유물 보상 버튼이 추가로 표시된다.
- 이미 보유한 유물은 후보에서 제외된다.
- 유물 1개를 획득할 수 있다.

| 영감의 커피 | 전투 시작 시 체력 3 회복 |
| 마감직전 | 체력이 10% 이하일 때 첫 번째 타일 재발동 |
| 불굴의 생명력 | 체력이 50% 이하일 때 전투 승리 시 체력 12 회복 |
| 밤샘 집필 | 체력이 50% 이하일 때 매 턴 카드 1장 드로우 |
| 마지막 빈칸 | 체력이 50% 이하일 때 다음 턴 시작 시 방어도 8 획득 |
| 회수되는 영감 | 전투 승리 시 체력 4 회복 |

## 13. 맵과 에피소드

### 13.1 큰 지도

- 큰 지도에는 해금된 에피소드가 표시된다.
- 처음에는 EP.1만 해금된다.
- 에피소드를 클리어하면 다음 에피소드가 해금된다.
- 이미 클리어한 에피소드는 다시 열 수 없다.

### 13.2 에피소드 선택 규칙

- 에피소드 데이터는 `Assets/Resources/Map/Episode{N}Map.json`에서 로드된다.
- 한 에피소드에서 표시되는 후보 노드 수는 최대 5개다.
- 후보 중 3개 노드를 선택해야 진행할 수 있다.
- 필수 노드가 있으면 반드시 선택해야 한다.
- 고정 선택 순서를 가진 노드는 자동 선택된다.
- 선택 순서가 실제 실행 순서가 된다.

## 14. 휴식

휴식 노드에서는 둘 중 하나를 선택한다.

- 회복: 최대 체력의 30%만큼 현재 체력 회복
- 카드 제거: 현재 런 덱에서 카드 1장 제거

덱에 카드가 1장 이하만 남아 있으면 마지막 카드는 제거할 수 없다.

## 15. 이벤트

## 16. 저장 시스템

## 18. 아트 방향

### 18.1 전체 톤

- 원고, 책, 잉크, 작가, 이야기 세계를 중심으로 한 판타지 분위기
- UI에는 양피지, 책상, 종이, 카드, 덱/버림 더미 아이콘이 사용된다.
- 적은 잉크와 문장, 원고 세계가 오염된 듯한 이미지로 구성된다.

### 18.2 캐릭터 방향

- 판타지 작가: 용사 서사와 영웅담을 만드는 작가 이미지
- 추리 작가: 단서, 사건, 수사, 진실 추적을 다루는 작가 이미지

### 18.3 적 방향

- 일반 적: 잉크 슬라임, 종이 귀신, 오탈자 등 원고 세계의 방해 요소
- 엘리트 적: 강한 문장/잉크/타락한 기사 컨셉
- 보스: 검은 잉크의 왕

## 19. 사운드 방향

현재 코드 기준으로 사운드 시스템은 GDD에서 구체 구현 대상으로 확인되지 않는다. 향후 사운드가 추가될 경우 아래 방향을 권장한다.

- 타이틀: 책장을 넘기는 소리, 잔잔한 서사적 음악
- 맵: 탐험감 있는 루프 음악
- 전투: 타격, 방어, 카드 배치, 카드 발동, 적 의도 전환 효과음
- 보상: 카드 선택, 유물 획득, 에피소드 해금 효과음

## 20. 밸런스 기준

### 20.1 기본 수치

- 시작 손패: 6장
- 턴마다 드로우: 6장
- 다시 뽑기 횟수: 전투당 2회
- 다시 뽑기 체력 비용: 5
- 휴식 회복량: 최대 체력의 30%
- 보드 크기: 12칸
- 카드 보상 선택지: 3장

### 20.2 캐릭터 밸런스 방향

- 판타지 작가는 높은 체력과 배치 보너스를 통해 안정적으로 큰 수치를 만든다.
- 추리 작가는 낮은 체력 대신 증거 자원을 이용해 고효율 효과를 노린다.
- 판타지 작가는 공간 설계 난도가 높고, 추리 작가는 자원 운영 난도가 높다.

### 20.3 적 밸런스 방향

- 일반 적은 기본 패턴과 소규모 버프로 압박한다.
- 엘리트는 높은 체력, 피해 제한, 가시 등 특정 대응을 요구한다.
- 보스는 피해 제한과 가시를 동시에 사용해 무작정 공격하는 전략을 억제한다.

## 21. 승리와 패배

### 21.1 승리

- 일반/엘리트 전투에서 적 체력을 0으로 만들면 해당 노드가 클리어된다.
- 보스 전투에서 보스를 처치하면 게임 클리어 패널이 표시된다.
- 에피소드의 선택 노드 3개를 모두 완료하면 에피소드가 클리어된다.

### 21.2 패배

- 플레이어 체력이 0이 되면 게임 오버 패널이 표시된다.
- 패배 시 런 데이터가 초기화된다.
